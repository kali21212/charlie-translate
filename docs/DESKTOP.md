# Charlie Translate 桌面版

Windows x64 便携版。完整解压后双击 `CharlieTranslate.exe`；无需另装 Python、Node、MTranServer 或填写 Key。不要只复制 EXE：`_internal`、`models`、`translation` 都是运行资源。

## 截图与悬浮按钮

1. 默认显示透明底、圆角的 C 图标悬浮按钮；拖动可移动，单击开始截图，右键可打开主窗口或隐藏。主窗口里的「悬浮截图按钮」可随时重新开启。
   图标默认纯绿色，无深色描边或阴影。右键选择「自定义图标颜色…」即可换色，立即生效且重启后保留；「恢复默认绿色」可一键重置。
2. 也可以点击「框选截图」或按 **Ctrl+Alt+Q**。框选完成后，截图保持在所选位置，下方出现紧凑图标工具栏；靠近屏幕底部时工具栏会显示在上方。没有大黑画布或独立编辑器标题栏。
   截图边框为 3 像素蓝线。工具按钮使用独立浅色底和 6 像素间距，绘图、隐私遮盖、编辑操作、完成操作之间带分隔线；选中按钮为蓝色，复制完成按钮为绿色。
3. 普通标注支持矩形、圆/椭圆、直线、箭头、铅笔、荧光笔、文字、序号、颜色、线宽、填充/描边、圆角、删除、撤销/重做。
4. 「隐私马赛克 / 隐私模糊 / 隐私遮盖」属于不可逆 Redact：应用时立即改写底层截图像素，并建立不可跨越的撤销边界；不能删除遮盖层恢复原内容。
5. 点击工具栏的 ✓ 或按 Enter，最终截图自动写入 Windows 剪贴板，截图界面直接收起；可以 **Ctrl+V**，不会自动弹出主窗口。点击「译」则打开主窗口，识字后自动翻译。图标悬停会显示中文提示。Esc 取消；Ctrl+Z/Y 撤销/重做普通标注。

## OCR 与本机翻译

桌面版内置 PP-OCRv5 增强 OCR、MTranServer 4.0.33 和当前英文→简体中文模型。点击「增强识字」后可编辑原文；点击「翻译为中文（本机）」时会自动启动内置 MTranServer，不需要单独运行服务。
EXE 启动后还会在回环地址提供两个受限服务：

- `127.0.0.1:8990`：浏览器截图 OCR。
- `127.0.0.1:8992`：浏览器扩展访问桌面内置翻译的桥接接口；内部随机 Token 与真正的 MTranServer `127.0.0.1:8991` 不暴露给浏览器。

因此更新后的 Charlie 浏览器插件进行整页、划词、字幕或截图翻译时，只需保持 EXE 开启；不再需要另外启动旧的 8989 MTranServer。当前内置模型范围仍是英文→简体中文，其他语言可继续显式配置其他接口。

关闭 EXE 会关闭 8990/8992 以及它自己启动的 8991 子进程。浏览器检测不到 8992 时会提示先打开 `CharlieTranslate.exe`，不会自动回退到云服务。

## 缓存与隐私

浏览器截图只作为内存中的 OCR 临时输入，不落盘。桌面版 Charlie 自己管理的缓存默认保留 **7 天**，可选 0/1/3/7/14/30 天；0 表示仅本次会话。程序启动时以及长时间运行期间会清理过期缓存。用户主动“另存为”的图片属于用户文件，不自动删除。

主窗口显示「缓存位置」和「默认保存位置」，可打开文件夹或修改路径，也可自行删除里面的文件。默认缓存位于 `%LOCALAPPDATA%\CharlieTranslate\cache`，默认手动保存位置为用户的 `Pictures\CharlieTranslate`。选择自定义缓存位置后，程序只管理所选文件夹中的 `CharlieTranslateCache` 子目录；其他文件不会参与自动清理。修改路径不搬移旧文件，旧缓存位置会显示在状态提示中。路径与有效期重启后保留。

浏览器翻译文字缓存默认 7 天；读取时检查过期，并在扩展后台启动及后续使用时清理到期条目。旧版没有时间戳的缓存会丢弃后重新生成。

截图、OCR 和 Redact 均在本机完成；截图不会发送给 MTranServer，翻译服务只接收文字。没有遥测、运行时模型下载或自动云回退。系统剪贴板仍可能被其他本机软件或 Windows 剪贴板同步读取，因此敏感内容应先 Redact 再完成复制。

## 开发与复现

桌面截图编辑器使用 Python Tk + Pillow 原生实现，没有把浏览器侧的图形依赖引入扩展。交互参考 ShareX/Flameshot/eSearch 的“后台常驻入口 + 框选后编辑 + 完成后复制”工作流；未直接复制第三方截图应用代码。

运行 `node desktop/prepare.mjs` 只在构建准备阶段下载并校验固定模型、Node 与 npm 依赖；随后运行 `python desktop/build.py`。输出 `build/desktop/CharlieTranslate`。正式发布应记录对应 Git 提交及压缩包 SHA-256。

### 自定义快捷键

主窗口点击“快捷键设置”，修改后点“保存”立即生效，并在下次启动保留。默认 `F1` 框选截图并进入标注，`F2` 框选后直接识字并翻译。点击快捷键输入框后直接按键录入；F1–F12 可单独使用，也支持 Ctrl / Alt / Shift 与字母、数字、F1–F12 的组合；两项不能重复。打开设置时暂时停用全局快捷键，避免录入按键触发截图；保存或取消后恢复。快捷键被其他软件占用时会提示，并恢复原来的绑定。“恢复默认”填入默认组合，点击保存后生效。原文框中按 `Ctrl+Enter` 翻译当前文字。

框选完成后自动复制图片到 Windows 剪贴板，可直接 Ctrl+V 粘贴到支持图片的聊天框。标注完成时自动再次复制最终图片。截图翻译也在识字前复制框选图片；不需要另点工具栏复制。

Windows 快捷键录入使用实际按下的 Ctrl/Alt/Shift 状态，NumLock 不算 Alt。识字时保留截图预览，显示运行进度条和已用时间；识字完成后自动显示原文并继续翻译。截图检测避免把小截图短边无条件放大到 736 像素，OCR 线程最多使用 8 个，并复用推理内存。

全局快捷键由独立 Windows 消息线程接收，避免 Tk 主循环提前消耗消息。重复启动会打开已有主窗口，不会建立第二个实例争抢快捷键。主窗口底部先保留操作、路径、进度和状态区域，缩小窗口时仍可看见识字提示与已用时间。

本机当前启动入口为 D:\f\Charlie-Translate-Desktop-V1\CharlieTranslate.exe；可编辑源码为 E:\Projects\charlie-translate。E:\Projects\charlie-translate-audit 是旧审计工作目录，其中 tmp/desktop-env 的构建环境仍用于当前打包，不是当前源码入口。
