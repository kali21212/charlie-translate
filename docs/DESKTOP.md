# Charlie Translate 桌面版

Windows x64 便携版。完整解压后双击 `CharlieTranslate.exe`；无需另装 Python、Node、MTranServer 或填写 Key。不要只复制 EXE：`_internal`、`models`、`translation` 都是运行资源。

## 截图与悬浮按钮

1. 默认显示透明底、圆角的 C 图标悬浮按钮；拖动可移动，单击开始截图，右键可打开主窗口或隐藏。主窗口里的「悬浮截图按钮」可随时重新开启。
   图标默认纯绿色，无深色描边或阴影。右键选择「自定义图标颜色…」即可换色，立即生效且重启后保留；「恢复默认绿色」可一键重置。
2. 也可以点击「框选截图」或按 **Ctrl+Alt+Q**。框选完成后，截图保持在所选位置，下方出现紧凑图标工具栏；靠近屏幕底部时工具栏会显示在上方。工具栏左侧有拖动把手，可移动到不遮挡内容的位置；没有大黑画布或独立编辑器标题栏。
   截图边框为 3 像素蓝线。工具按钮按普通标注、安全隐私、撤销编辑和输出动作分组；工具属性只显示当前工具需要的第二行选项，避免把所有控制项长期堆在界面上。
3. 普通标注支持矩形、圆/椭圆、直线、箭头、铅笔、荧光笔、文字、序号、颜色、线宽、填充/描边、圆角、删除、撤销/重做。
4. 隐私工具统一为一个「隐私抹除」入口，第二行可选「实色抹除（默认、最强）/ 安全马赛克 / 安全模糊」。三种模式都属于 Charlie 不可逆 Redact：拖框提交时先把之前的普通标注合成到截图（之前的标注随之不可再编辑），再永久抹除指定区域并清空 Undo/Redo 历史，防止任何旧标注叠在抹除区上方；马赛克与模糊使用与原始敏感像素无关的合成图案，不以原图像素计算效果，因此从处理后的截图无法推断被抹除区域。不存在可删除的遮盖层来恢复原内容。没有引入 Snow Shot 的多套可逆滤镜/马赛克模型。
5. 为防止未抹除的原始截图提前进入剪贴板，框选进入标注编辑器时不立即复制；只有点击 ✓、按 Enter 或完成保存/识字输出时，最终截图才写入 Windows 剪贴板并收起；点击保存会在自动复制后打开保存流程；点击「译」则打开主窗口，识字后自动翻译。图标悬停显示中文提示。Esc 取消；Ctrl+Z/Y 仅撤销/重做普通标注。

## OCR 与本机翻译

桌面版内置 PP-OCRv5 增强 OCR、MTranServer 4.0.33 和当前英文→简体中文模型。增强识字默认使用 OCR 坐标自动重建阅读顺序、栏区、标题、段落、断词与中英文间距，避免“一行一个硬换行”把长文章排得支离破碎；设置中可关闭，也可对编辑后的原文点击「整理段落」再次整理。

主翻译窗口可自由缩放并记住上次大小：宽窗口时原文/译文左右双栏，窄窗口时自动改为上下两栏；两侧都有独立滚动条与 word-wrap。长文章翻译会按段落切块、按受控批次送入本地 MTranServer，再恢复段落结构，不再把整篇文章塞进单一固定请求。

点击「增强识字」后可编辑原文；点击「翻译为中文（本机）」时会自动启动内置 MTranServer，不需要单独运行服务。EXE 启动后还会在回环地址提供两个受限服务：

- `127.0.0.1:8990`：浏览器截图 OCR。
- `127.0.0.1:8992`：浏览器扩展访问桌面内置翻译的桥接接口；内部随机 Token 与真正的 MTranServer `127.0.0.1:8991` 不暴露给浏览器。

Translation Router V2 下，浏览器整页、划词、输入框和字幕翻译会先检测浏览器本地 `Translator` API；当前语言对可用时直接在浏览器本地完成，不要求 EXE 运行。浏览器没有该能力或语言对失败时，才回退到 EXE 的 8992/MTranServer。截图翻译的增强 OCR 仍需要 EXE 的 8990。

关闭 EXE 会关闭 8990/8992 以及它自己启动的 8991 子进程。如果浏览器本地 Translator 同时不可用，Charlie 会明确提示打开 `CharlieTranslate.exe`；**不会自动回退到云服务**。当前 Desktop 内置 MTran 模型范围仍是英文→简体中文。

## 缓存与隐私

浏览器截图只作为内存中的 OCR 临时输入，不落盘。桌面版 Charlie 自己管理的缓存默认保留 **7 天**，可选 0/1/3/7/14/30 天；0 表示仅本次会话。程序启动时以及长时间运行期间会清理过期缓存。用户主动“另存为”的图片属于用户文件，不自动删除。

主窗口改为紧凑工作区；缓存期限、缓存位置、默认保存位置、OCR 自动段落整理和快捷键入口集中到右上角「设置」，不再长期占用文章阅读空间。默认缓存位于 `%LOCALAPPDATA%\CharlieTranslate\cache`，默认手动保存位置为用户的 `Pictures\CharlieTranslate`。选择自定义缓存位置后，程序只管理所选文件夹中的 `CharlieTranslateCache` 子目录；其他文件不会参与自动清理。修改路径不搬移旧文件，旧缓存位置会显示在状态提示中。窗口大小、段落整理开关、路径与有效期重启后保留。

浏览器翻译文字缓存默认 7 天；读取时检查过期，并在扩展后台启动及后续使用时清理到期条目。旧版没有时间戳的缓存会丢弃后重新生成。

截图、OCR 和 Redact 均在本机完成；截图不会发送给 MTranServer，翻译服务只接收文字。没有遥测、运行时模型下载或自动云回退。普通标注模式会在完成编辑后复制最终图片，不再预先复制原始敏感截图；直接截图并翻译仍会复制未抹除的截图，不能用于需要抹除隐私的场景。Windows 剪贴板历史/同步或其他软件仍可能保留旧版本已经复制过的图片，本工具不能清除那些外部历史，处理敏感内容时建议关闭相关功能。

## 开发与复现

桌面截图编辑器使用 Python Tk + Pillow 原生实现，没有把浏览器侧的图形依赖引入扩展。V2.4 Desktop 刷新继续参考 ShareX/Flameshot/eSearch，并新增参考 Snow Shot 的“紧凑可移动工具栏 + 当前工具上下文属性 + 自适应翻译窗口”交互；Snow Shot 的 Qt/Rust UI、滤镜与马赛克实现未被引入。OCR 智能排版参考 Snow Shot 所采用的 STranslate Smart Layout 设计原则，以 Charlie/RapidOCR 的 Python 数据结构重新实现。来源与 License 记录见 `UPSTREAM.md`。

运行 `node desktop/prepare.mjs` 只在构建准备阶段下载并校验固定模型、Node 与 npm 依赖；随后运行 `python desktop/build.py`。默认输出 `build/desktop/CharlieTranslate`。若当前旧便携版不能替换，先通过环境变量 `CHARLIE_DESKTOP_DISTPATH`、`CHARLIE_DESKTOP_WORKPATH`、`CHARLIE_DESKTOP_SPECPATH` 将输出、PyInstaller 中间文件和 spec 分别指定到隔离测试目录。构建入口拒绝 Git 工作树存在未提交改动，防止 `SOURCE.txt` 标记的 commit 与实际代码不符。正式发布应记录对应 Git 提交及压缩包 SHA-256。

### 自定义快捷键

主窗口点击“快捷键设置”，修改后点“保存”立即生效，并在下次启动保留。默认 `F1` 框选截图并进入标注，`F2` 框选后直接识字并翻译。点击快捷键输入框后直接按键录入；F1–F12 可单独使用，也支持 Ctrl / Alt / Shift 与字母、数字、F1–F12 的组合；两项不能重复。打开设置时暂时停用全局快捷键，避免录入按键触发截图；保存或取消后恢复。快捷键被其他软件占用时会提示，并恢复原来的绑定。“恢复默认”填入默认组合，点击保存后生效。原文框中按 `Ctrl+Enter` 翻译当前文字。

框选后进入标注编辑器，不会提前复制未经隐私抹除的截图；点击完成后自动复制最终图片，可直接 Ctrl+V 粘贴。截图直接翻译流程仍会在识字前复制框选图片（该流程不提供隐私抹除）；不需要另点工具栏复制。

Windows 快捷键录入使用实际按下的 Ctrl/Alt/Shift 状态，NumLock 不算 Alt。识字时保留截图预览，显示运行进度条和已用时间；识字完成后自动显示原文并继续翻译。截图检测避免把小截图短边无条件放大到 736 像素，OCR 线程最多使用 8 个，并复用推理内存。

全局快捷键由独立 Windows 消息线程接收，避免 Tk 主循环提前消耗消息。重复启动会打开已有主窗口，不会建立第二个实例争抢快捷键。主窗口底部只保留翻译/段落整理/复制、悬浮/置顶、进度和状态；路径与缓存设置移入设置窗口。窗口缩小时原文/译文自动切成上下布局，仍可看见识字提示与已用时间。

便携版启动入口为解压目录中的 `CharlieTranslate.exe`。开发构建应使用安装了固定依赖的 Python 环境；源码目录和构建环境可以分别存放。
