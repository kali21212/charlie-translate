# 浏览器截图翻译

浏览器版不承担通用截图软件功能。截图入口固定为：

`框选网页区域 → 本地 OCR → 自动翻译 → 显示原文与译文`

1. 先打开 Charlie Translate Desktop；EXE 会提供本机 OCR（127.0.0.1:8990）和桌面翻译桥（127.0.0.1:8992）。
2. 点击「截图翻译」，拖动选择当前可见网页区域，Esc 可取消。
3. 截图只在内存里作为 OCR 临时输入，不显示图片编辑器、不提供保存图片或复制图片。
4. OCR 完成后立即使用当前选择的翻译接口自动翻译。默认 MTranServer 配置会连接 EXE 的 8992 桥接服务；旧版默认的 8989 本地配置会自动迁移到 8992（显式配置 Key 或自定义地址不会被覆盖）。
5. 浏览器可复制 OCR 原文或译文。没有截图文件缓存，因此截图留存期实际上为 0 天。

如果 EXE 没有运行，使用默认本机接口时会明确提示先打开 `CharlieTranslate.exe`，不会自动把文字发送到云端。当前 EXE 内置翻译模型为英文→简体中文；主动选择其他云接口时，文字会发送至对应服务。

敏感 URL、密码/OTP/密钥字段或页面状态检查失败时仍拒绝浏览器截图。浏览器版不加入矩形、箭头、马赛克、Redact 等通用截图编辑能力；这些只存在于 Windows 桌面版。
