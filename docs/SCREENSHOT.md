# 浏览器截图翻译

浏览器版不承担通用截图软件功能。截图入口固定为：

`框选网页区域 → 本地 OCR → 自动翻译 → 显示原文与译文`

1. 先打开 Charlie Translate Desktop；EXE 会提供本机 OCR（127.0.0.1:8990）和桌面翻译桥（127.0.0.1:8992）。
2. 点击「截图翻译」，拖动选择当前可见网页区域，Esc 可取消。
3. 截图只在内存里作为 OCR 临时输入，不显示图片编辑器、不提供保存图片或复制图片。
4. OCR 完成后立即使用当前选择的翻译接口自动翻译。默认 `CharlieAuto` 会先尝试浏览器 Translator API，再回退到已运行 Desktop 的 8992/MTranServer；不会自动进入云端。旧版默认 8989 无 Key 本地配置会迁移到 8992（显式 Key 或自定义地址不覆盖）。
5. 浏览器可复制 OCR 原文或译文。没有截图文件缓存，因此截图留存期实际上为 0 天。

截图翻译的增强 OCR 依赖 EXE，因此截图场景仍应先打开 `CharlieTranslate.exe`。对普通网页/划词/输入框/字幕翻译，支持浏览器 Translator API 的环境可在 EXE 关闭时继续本地翻译；不支持时才要求 Desktop fallback。任何本地失败都不会自动把文字发送到云端；只有用户主动选择云接口时才会发送至对应服务。

敏感 URL、密码/OTP/密钥字段或页面状态检查失败时仍拒绝浏览器截图。浏览器版不加入矩形、箭头、马赛克、Redact 等通用截图编辑能力；这些只存在于 Windows 桌面版。
