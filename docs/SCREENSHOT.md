# 浏览器截图与翻译

打开网页悬浮按钮菜单中的「截图与翻译」。

1. 打开 Charlie Translate 桌面版，等待「增强 OCR 就绪」；浏览器与桌面共用本机模型，不需要 Key。
2. 点击「框选截图」，拖动选择当前可见网页区域，Esc 取消。
3. 检查预览，点击「本地识字」，使用 PP-OCRv5 增强 OCR。原文可编辑；不会自动翻译。
4. 选择接口和目标语言，再点击「翻译」。MTranServer 网页翻译接口需要单独运行在 8989；桌面版自带的私有翻译服务只供桌面使用。
5. 可以主动复制或保存截图、原文及译文。

已移除轻量 Tesseract 引擎、语言选择和 offscreen 权限。OCR 请求只发送至 `http://127.0.0.1:8990`，先验证服务身份，禁止重定向，没有云 OCR 备选。未启动桌面版时明确提示。停止操作会丢弃结果；已经开始的本机推理可能短暂继续，但不会显示过期结果。

扩展只支持普通 HTTP/HTTPS 网页当前可见区域。敏感 URL、密码/OTP/密钥字段或检查失败时拒绝截图；页面跳转、标签切换、缩放和滚动会丢弃结果。浮窗属于网页 DOM，页面脚本可能读取其中显示的图片和文字，因此不是秘密保管容器。桌面截图不受浏览器范围限制，但不能自动识别所有秘密，先检查预览。

只有点击翻译才发送文字：MTranServer 在本机，主动选择云翻译接口则会发送文字到该云服务。桌面版不提供云接口。保存窗口被取消时不会报告成功；可使用复制截图。主动复制会写入系统剪贴板。
